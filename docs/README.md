# cfhub Guides

Use these guides to install cfhub, set access, run commands, and resolve common errors.

## Guide index

| Guide                                          | Use it to                                      |
| ---------------------------------------------- | ---------------------------------------------- |
| [Setup and first use](getting-started.md)      | Install cfhub and run your first read command. |
| [Profiles and settings](configuration.md)      | Set tokens, profiles, paths, and defaults.     |
| [Command reference](commands.md)               | Find resource commands and common actions.     |
| [Output and safe writes](output-and-safety.md) | Format output and preview or confirm writes.   |
| [OAuth access](oauth-scopes.md)                | Set up OAuth and select access scopes.         |
| [Local extensions](extensions.md)              | Install and manage local commands.             |

Run `cfhub --help` and `cfhub <resource> --help` for command options. Command help is the source for exact flags and action details.
