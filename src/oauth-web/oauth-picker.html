Frequently asked questions

What does “Keep me logged in” do?

When selected, cfhub requests Cloudflare's offline_access permission. If your OAuth client allows refresh tokens, the profile can renew itself after the roughly one-hour access-token lifetime. It is off by default because it creates a longer-lived credential. If you leave it off, you will need to authorize again when the access token expires.

What are scopes?

Scopes are permissions granted to cfhub by Cloudflare. Each scope controls a capability, such as reading zones or changing DNS records. Choose only the permissions you expect to use.

What do the modules do?

Modules group the scopes used by built-in cfhub commands. Enabling a module selects its required permissions; shared permissions stay selected while another enabled module still needs them.

How do I use custom scopes with cfhub api?

Expand the full scope list and select the permissions for the Cloudflare endpoints you plan to call with cfhub api. The raw API command can reach endpoints beyond the built-in modules, so its required scopes depend on the endpoint and HTTP method you use.

Can I add permissions later?

Yes. Run cfhub oauth login again, select the additional permissions, and authorize the updated profile. Existing credentials are replaced with the new authorization.

Can I use my own OAuth client?

Yes. Create a Cloudflare OAuth application in your own account or organization, enable the authorization-code flow, and register the local callback URL http://127.0.0.1:8765/oauth/callback. If your client registration supports multiple redirect URLs, also register ports 8766 through 8769 because cfhub uses them as fallbacks when a port is busy. Select every Cloudflare scope your client should be allowed to request. Then start the normal login command with your client ID: 

CFHUB_OAUTH_CLIENT_ID=your-client-id cfhub oauth login

The command starts the local OAuth web server and opens the scope picker for you; no separate server command is required. The picker can only request scopes allowed by your Cloudflare client. For a remote or headless setup, keep the registered redirect host at 127.0.0.1 and use CFHUB_OAUTH_BIND_HOST=0.0.0.0 if the browser reaches the machine through another address.

Can Eliware access my Cloudflare account?

No. The default Eliware OAuth client identifies the application, but cfhub sends the authorization flow directly between your browser and Cloudflare. The resulting credentials are stored locally in your operating-system keychain and API calls go directly from cfhub to Cloudflare. Eliware does not receive your token, proxy your requests, or choose permissions on your behalf. You can use your own OAuth client at any time if you prefer to manage the client registration yourself.
